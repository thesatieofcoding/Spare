# Shared hostname vectors: `accept|host` or `reject|host`, one per line.
# Read by contracts/registry (src/test.rs, include_str!) and
# packages/spare-sdk (test/hostname-parity.test.ts) so both stay in agreement.
#
# Vectors are lowercase bare hosts ONLY. The contract validates lowercase-only
# (one stored form per domain); the SDK HOSTNAME_RE is case-insensitive (/i)
# and its caller lowercases input first. Uppercase is therefore deliberately
# NOT a shared vector: contract rejects it, SDK normalizes and accepts it.
#
# `example.org.` and `example.org/path` are not shared either: the SDK normalizes
# input (strips a trailing dot and any path) before the regex, while the contract
# takes the stored hostname verbatim and rejects both.
